# CCH-OS Stage 0 Exit Criteria v0.1

Stage 0 is complete only when:

- repository topology exists;
- foundational boundaries are represented;
- test harness/validation entrypoint executes;
- CI executes the foundation validation;
- prohibited foundation dependencies have an executable guard;
- no architecture claim is upgraded merely because the repository skeleton exists.

Current scope is repository foundation only. Semantic/runtime implementation belongs to later stages.
